画面背景 (screens.*.bg)

アプリアイコン (icons)

フォント (.bin)

lv_binfont 形式。TTF→変換は tools/gen_fonts.py --binfont <ttf> --size N。

スキン (kit.html)

テーマの kit.html を読み込むと iframe プレビューと CSS 変数の編集ができる。書き出しは (a) 編集済み kit.html → tools/build_themes.py --kit、または (b) ブラウザだけで PNG 化。

任意アセット (v5 assets)

id → ファイルの自由 map。id は a-z 0-9 _ . - 32字まで。 時計側は theme_image("<id>") で遅延ロード。アプリのアイコンは "icon.<アプリid>"、deco/face_layout の画像は任意の id。

入出力

theme.json

tools/theme_build.py と同じ形式。style / mascot / skin など 未対応キーは zip 書き出しで失われるので、警告が出たら theme_build.py で組む。
